Set up · about 20 minutes

Set up your Windows PC

OS tools are easiest on Linux, and Windows can run Linux inside it with WSL (Windows Subsystem for Linux). You install Ubuntu once, then everything happens in its terminal. Windows 11 is best; Windows 10 works too.

  1. Install WSL and Ubuntu

    Open the Start menu, type PowerShell, right-click it and choose Run as administrator. Then:

    wsl --install

    Restart your PC when it asks. Ubuntu opens by itself after the restart (or open Ubuntu from the Start menu). Choose a username and a password for Linux. Nothing shows while you type the password: that's normal. Remember it, you'll need it for sudo.

  2. Install the compiler and QEMU

    In the Ubuntu window (not PowerShell):

    sudo apt update && sudo apt install -y clang lld make git qemu-system-x86 qemu-system-gui

    clang is the C compiler, lld the linker that puts the pieces together, qemu the emulated PC. This is the exact command our automatic test uses, so it works.

  3. Check it worked

    clang --version
ld.lld --version
qemu-system-i386 --version

  4. Get the starter and run it

    Stay in your Linux home folder (cd ~). Don't work in /mnt/c/…: it is much slower there.

    cd ~
git clone https://github.com/alajemba-vik/build-your-own-os.git
cp -R build-your-own-os/starter my-os
cd my-os
git init && git add -A && git commit -m "Start from the starter"
make run

    On Windows 11 a QEMU window opens with "Hello from my own operating system!". That is your OS. To stop it, close the window or press Ctrl C in Ubuntu.

    No window (Windows 10)? Run make run-text: the screen of your OS shows inside the Ubuntu window. Quit with Esc then 2, type quit, Enter.

    The first time, Git may ask who you are. Run these with your own name and email, then the commit again:

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

  5. Open it with your AI

    VS Code: install it on Windows with the WSL extension, then in Ubuntu, in my-os, run code .. Cursor works the same way. Terminal AIs (Claude Code, Codex, Gemini CLI) install and run inside Ubuntu, in the my-os folder.

    code .        # VS Code (with Copilot) through WSL
claude        # Claude Code, in the my-os folder

    Using a chat AI instead? Open my-os/AGENTS.md (in VS Code, or with cat AGENTS.md), copy all of it and paste it as your first message.

"Please enable the Virtual Machine Platform" or error 0x80370102: virtualization is off. Turn on Virtualization (Intel VT-x / AMD-V / SVM) in your PC's BIOS settings, then run wsl --install again.

wsl --install only shows help text: WSL is already there. Run wsl --install -d Ubuntu, then wsl --update.
