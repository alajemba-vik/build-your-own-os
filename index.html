What is an operating system?

It is the program that runs first and owns the computer: it talks to the hardware (screen, keyboard, memory, timer), it decides what runs when, and it gives other programs a simple way to use all of it. Windows, macOS, Linux, Android and iOS are operating systems. At its centre is the kernel, and that is what we build.

When you press the power button, this is what happens. You will write the parts in bold:

Power on→Firmware (BIOS)→Bootloader→boot.S→kernel_main()→drivers→your shell

Will it replace Windows or macOS?

No. Your OS runs inside QEMU, a free program that pretends to be a whole PC (an emulator). Nothing on your computer changes, and if your OS crashes you just close the window. It is a real OS all the same: the same code could start a real PC.

We build for the classic 32-bit Intel PC (x86), because it is the best documented and the simplest to start. It runs the same on Intel Macs, Apple Silicon Macs (M1–M4) and Windows PCs.

How to vibe-code an OS

You describe what you want, the AI writes code, and you run it, read it and steer. An OS is a great place for this: the AI knows the hardware tricks, and you learn what each one does. Five rules that make it work:

  1. Give your AI the brief. The starter comes with AGENTS.md: the rules of the project (32-bit, no C library, clang, QEMU…). Coding agents read it by themselves; with a chat AI, paste it first.
  2. One chapter, one step at a time. Each chapter gives you a prompt. Don't ask for the whole OS at once: you would get something you can't fix.
  3. Ask why, not only what. Every chapter has questions to ask. If you can't explain a line, ask until you can.
  4. Run it after every change with make run. When it breaks, paste the full error to the AI.
  5. Save with Git when something works. Stuck? Each chapter has the reference code from a finished OS to compare with.

Which AI?

Coding agents

Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI. They read the files in your folder and AGENTS.md, edit the code and can run make. The easiest choice.

Chat AIs

ChatGPT, Claude.ai, Gemini. Paste AGENTS.md at the start, then paste the files you want changed, and copy the answers back into your files.

No AI?

That works too. Each chapter explains the idea, and the reference code is fully commented. Read it, then write it yourself.
