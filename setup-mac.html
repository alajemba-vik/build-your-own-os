Set up · about 15 minutes

Set up your Mac

You need three things: the Apple developer tools (Git and make), a compiler that can build for a PC (LLVM's clang and lld), and QEMU to run your OS. Intel and Apple Silicon Macs both work.

  1. Open Terminal

    Press ⌘ Space, type Terminal, press Return. Paste each command below and press Return.

  2. Install the Apple developer tools

    xcode-select --install

    A window opens: click Install. If it says they are already installed, that's fine: go on.

  3. Install Homebrew

    Homebrew installs developer tools with one command. Skip this if brew --version already works.

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    It asks for your Mac password (nothing shows while you type: that's normal). At the end it prints "Next steps" with two or three commands: run them, then close Terminal and open it again.

  4. Install the compiler and QEMU

    brew install llvm lld qemu

    This takes 5 to 10 minutes. llvm gives you clang, the C compiler, lld the linker that puts the pieces together, and qemu the emulated PC.

  5. Check it worked

    "$(brew --prefix llvm)/bin/clang" --version
ls "$(brew --prefix lld)/bin/ld.lld"
qemu-system-i386 --version

    Each line should print a version or a path, not "command not found" or "No such file".

  6. Get the starter and run it

    cd ~
git clone https://github.com/alajemba-vik/build-your-own-os.git
cp -R build-your-own-os/starter my-os
cd my-os
git init && git add -A && git commit -m "Start from the starter"
make run

    A QEMU window opens with "Hello from my own operating system!". That is your OS. To stop it, close the window or press Ctrl C in Terminal.

    The first time, Git may ask who you are. Run these with your own name and email, then the commit again:

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

  7. Open it with your AI

    Open the my-os folder in your editor or AI tool. For example:

    code .        # VS Code (with Copilot), or: cursor .
claude        # Claude Code, in the my-os folder
codex         # Codex CLI, in the my-os folder

    Using a chat AI instead? Open my-os/AGENTS.md, copy all of it and paste it as your first message.

"command not found: brew": you missed the "Next steps" lines at the end of the Homebrew install. Run eval "$(/opt/homebrew/bin/brew shellenv)" (Apple Silicon) or eval "$(/usr/local/bin/brew shellenv)" (Intel), and add that line to ~/.zprofile.

The QEMU window doesn't show up: look for it behind Terminal or in the Dock. Or run make run-text to see the screen inside Terminal (quit with Esc then 2, type quit, Return).
