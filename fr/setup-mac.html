Installation · environ 15 minutes

Préparez votre Mac

Il vous faut trois choses : les outils de développement d’Apple (Git et make), un compilateur capable de produire du code pour PC (clang et lld, de LLVM), et QEMU pour faire tourner votre OS. Les Mac Intel et Apple Silicon conviennent tous les deux.

  1. Ouvrez le Terminal

    Appuyez sur ⌘ Espace, tapez Terminal, appuyez sur Entrée. Collez chaque commande ci-dessous et appuyez sur Entrée.

  2. Installez les outils de développement d’Apple

    xcode-select --install

    Une fenêtre s’ouvre : cliquez sur Installer. S’il est indiqué qu’ils sont déjà installés, pas de souci : continuez.

  3. Installez Homebrew

    Homebrew installe des outils de développement en une commande. Passez cette étape si brew --version fonctionne déjà.

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Il demande le mot de passe de votre Mac (rien ne s’affiche pendant la saisie : c’est normal). À la fin, il affiche « Next steps » avec deux ou trois commandes : lancez-les, puis fermez le Terminal et rouvrez-le.

  4. Installez le compilateur et QEMU

    brew install llvm lld qemu

    Comptez 5 à 10 minutes. llvm fournit clang, le compilateur C, lld l’éditeur de liens qui assemble les morceaux, et qemu le PC émulé.

  5. Vérifiez que ça a marché

    "$(brew --prefix llvm)/bin/clang" --version
ls "$(brew --prefix lld)/bin/ld.lld"
qemu-system-i386 --version

    Chaque ligne doit afficher une version ou un chemin, et non « command not found » ou « No such file ».

  6. Récupérez le kit de départ et lancez-le

    cd ~
git clone https://github.com/alajemba-vik/build-your-own-os.git
cp -R build-your-own-os/starter my-os
cd my-os
git init && git add -A && git commit -m "Start from the starter"
make run

    Une fenêtre QEMU s’ouvre avec « Hello from my own operating system! ». C’est votre OS. Pour l’arrêter, fermez la fenêtre ou appuyez sur Ctrl C dans le Terminal.

    La première fois, Git peut vous demander qui vous êtes. Lancez ces commandes avec votre nom et votre e-mail, puis refaites le commit :

    git config --global user.name "Votre Nom"\ngit config --global user.email "vous@example.com"

  7. Ouvrez-le avec votre IA

    Ouvrez le dossier my-os dans votre éditeur ou votre outil d’IA. Par exemple :

    code .        # VS Code (avec Copilot), ou : cursor .
claude        # Claude Code, dans le dossier my-os
codex         # Codex CLI, dans le dossier my-os

    Vous utilisez plutôt une IA de chat ? Ouvrez my-os/AGENTS.md (ou lisez-le sur GitHub), copiez-le en entier et collez-le comme premier message.

« command not found: brew » : vous avez manqué les lignes « Next steps » à la fin de l’installation de Homebrew. Lancez eval "$(/opt/homebrew/bin/brew shellenv)" (Apple Silicon) ou eval "$(/usr/local/bin/brew shellenv)" (Intel), et ajoutez cette ligne à ~/.zprofile.

La fenêtre QEMU n’apparaît pas : cherchez-la derrière le Terminal ou dans le Dock. Ou lancez make run-text pour voir l’écran dans le Terminal (pour quitter : Échap puis 2, tapez quit, Entrée).
