Installation · environ 20 minutes

Préparez votre PC Windows

Les outils pour écrire un OS s’utilisent le plus facilement sous Linux, et Windows peut faire tourner Linux grâce à WSL (Windows Subsystem for Linux). Vous installez Ubuntu une fois, puis tout se passe dans son terminal. Windows 11 est l’idéal ; Windows 10 fonctionne aussi.

  1. Installez WSL et Ubuntu

    Ouvrez le menu Démarrer, tapez PowerShell, faites un clic droit dessus et choisissez Exécuter en tant qu’administrateur. Puis :

    wsl --install

    Redémarrez votre PC quand il le demande. Ubuntu s’ouvre tout seul après le redémarrage (sinon, ouvrez Ubuntu depuis le menu Démarrer). Choisissez un nom d’utilisateur et un mot de passe pour Linux. Rien ne s’affiche pendant la saisie du mot de passe : c’est normal. Retenez-le, il vous servira pour sudo.

  2. Installez le compilateur et QEMU

    Dans la fenêtre Ubuntu (pas PowerShell) :

    sudo apt update && sudo apt install -y clang lld make git qemu-system-x86 qemu-system-gui

    clang est le compilateur C, lld l’éditeur de liens qui assemble les morceaux, qemu le PC émulé. C’est exactement la commande qu’utilise notre test automatique : elle fonctionne.

  3. Vérifiez que ça a marché

    clang --version
ld.lld --version
qemu-system-i386 --version

  4. Récupérez le kit de départ et lancez-le

    Restez dans votre dossier personnel Linux (cd ~). Ne travaillez pas dans /mnt/c/… : c’est beaucoup plus lent.

    cd ~
git clone https://github.com/alajemba-vik/build-your-own-os.git
cp -R build-your-own-os/starter my-os
cd my-os
git init && git add -A && git commit -m "Start from the starter"
make run

    Sous Windows 11, une fenêtre QEMU s’ouvre avec « Hello from my own operating system! ». C’est votre OS. Pour l’arrêter, fermez la fenêtre ou appuyez sur Ctrl C dans Ubuntu.

    Pas de fenêtre (Windows 10) ? Lancez make run-text : l’écran de votre OS s’affiche dans la fenêtre Ubuntu. Pour quitter : Échap puis 2, tapez quit, Entrée.

    La première fois, Git peut vous demander qui vous êtes. Lancez ces commandes avec votre nom et votre e-mail, puis refaites le commit :

    git config --global user.name "Votre Nom"\ngit config --global user.email "vous@example.com"

  5. Ouvrez-le avec votre IA

    VS Code : installez-le sous Windows avec l’extension WSL, puis dans Ubuntu, dans my-os, lancez code .. Cursor fonctionne de la même façon. Les IA en terminal (Claude Code, Codex, Gemini CLI) s’installent et se lancent dans Ubuntu, dans le dossier my-os.

    code .        # VS Code (avec Copilot) via WSL
claude        # Claude Code, dans le dossier my-os

    Vous utilisez plutôt une IA de chat ? Ouvrez my-os/AGENTS.md (dans VS Code, avec cat AGENTS.md, ou sur GitHub), copiez-le en entier et collez-le comme premier message.

« Please enable the Virtual Machine Platform » ou erreur 0x80370102 : la virtualisation est désactivée. Activez la virtualisation (Intel VT-x / AMD-V / SVM) dans les réglages du BIOS de votre PC, puis relancez wsl --install.

wsl --install n’affiche que l’aide : WSL est déjà là. Lancez wsl --install -d Ubuntu, puis wsl --update.
