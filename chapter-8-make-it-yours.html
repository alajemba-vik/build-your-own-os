Chapter 8 · as long as you like

Make it yours and share it

You have a working operating system: a boot process, drivers, a crash screen, a shell, a memory allocator and a desktop. Now give it a name, add the feature you want, and show it to the club.

Give it a name

Change OS_NAME in src/os.h, and ask your AI for a new ASCII-art logo with that name.

Ideas, easy to hard

IdeaWhat you learn
Themes: a theme command that recolours the shell and the desktopVGA colours
Real date and time from the PC's clock chip, in the top barThe CMOS RTC (ports 0x70/0x71)
AZERTY keyboard, and a layout commandScancodes
A game: snake, pong, or 2048 in a windowGame loop, timer, randomness
A notepad that keeps notes while the OS runskmalloc, strings
Sound: a beep at boot from the PC speaker (run QEMU with -audiodev and -machine pcspk-audiodev=…)PIT channel 2
A better heap with kfreeFree lists, fragmentation
Paging: give the kernel its own view of memoryPage tables, CR3, page faults
Multitasking: two tasks taking turns on the timerContext switches, scheduling
Graphics mode: pixels instead of charactersFramebuffers (bootloaders like GRUB or Limine)

I finished the 8 chapters of the tutorial. I want to add: [YOUR IDEA]. First explain how it works on real PC hardware and which parts of my OS need to change. Then break it into 3 to 5 small steps I can test one by one, and do only the first step.

When you outgrow this, the OSDev wiki is the place real hobby-OS builders learn from. Projects like SerenityOS started exactly where you are now.

Put it on GitHub

With the GitHub CLI (brew install ghsudo apt install gh, then gh auth login), in your my-os folder:

gh repo create my-os --public --source . --push

Or create an empty repository on github.com and follow its "push an existing repository" steps. Then take a screenshot of your desktop and add it to your README.md.

Show it to the club

  • Bring it to a Thursday session and show it. Two minutes is enough: what you added, and what was hard.
  • Post your screenshot and repository link in the club's WhatsApp group.
  • Want it on the club website? Ask an organizer to add it to the student apps showcase.
