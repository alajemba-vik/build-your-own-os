# My OS

A tiny operating system for 32-bit x86 PCs, written in C from scratch and run in QEMU.
Started from the aivancity Tech Club tutorial: https://alajemba-vik.github.io/build-your-own-os/

```bash
make run        # build it and start it in QEMU
make run-text   # same, but the screen shows inside the terminal
make clean
```
