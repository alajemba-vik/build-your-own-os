Help

Stuck? Start here

Almost every problem is in the table below. If not, ask your AI the right way, or ask in the room.

Ask your AI the right way

I'm on chapter [N] of the build-your-own-OS tutorial (32-bit x86, multiboot, clang + ld.lld, QEMU, no C library: see AGENTS.md). I changed: [WHICH FILES, WHAT]. I ran: [THE COMMAND]. I expected: [WHAT SHOULD HAPPEN]. Instead I see: [WHAT HAPPENS, AND THE FULL ERROR OR THE LAST LINES OF OUTPUT]. Explain what the error means first, then give me the smallest fix.

The full error matters: paste everything from the first red line. For crashes, paste the panic screen or the output of the -d int,cpu_reset command below.

Common problems

You seeWhat it means and what to do
clang: command not found or ld.lld: No such fileThe tools aren't installed or not found. Mac: brew install llvm lld. Windows: run the sudo apt install … line from the setup in Ubuntu. Check you are in the Ubuntu window, not PowerShell.
Errors about i686-elf or ld.lld on a MacApple's own clang is probably being used. Run brew install llvm lld; the Makefile then finds Homebrew's version by itself.
make: *** No targets specified or No rule to make targetYou are not in your OS folder. Run cd ~/my-os.
undefined symbol: memset / memcpyThe compiler uses them for big copies. Write them in src/string.c (chapter 2).
undefined symbol: __udivdi3 / __umoddi3A 64-bit division or %. Use a shift, or 32-bit numbers.
fatal error: 'stdio.h' file not foundThere is no C library in a kernel. Use your own kprintf. Only stdint.h, stddef.h, stdbool.h and stdarg.h exist.
QEMU says Error loading uncompressed kernel without PVH ELF NoteQEMU didn't find the multiboot header. Check .multiboot comes first in linker.ld, the magic number is right, and you built for i686 (32-bit).
QEMU opens and closes right awayA triple fault (a crash while handling a crash). See below.
Typing does nothingClick inside the QEMU window first. Then check sti, that IRQ 1 is unmasked, and the End Of Interrupt (chapter 4).
Letters are in the wrong placesYour keyboard is AZERTY and the table is QWERTY. Expected; see chapter 4's challenge.
No QEMU window on WindowsWindows 10 has no window support for Linux apps. Use make run-text. On Windows 11, run wsl --update in PowerShell, then wsl --shutdown, and open Ubuntu again.
Stuck inside make run-textPress Esc then 2, type quit, Enter. Or close the terminal.
The mouse is stuck in the QEMU windowPress Ctrl Alt G (Mac: Ctrl ⌥ G).
It worked before and now it's brokengit diff shows what changed since your last save. git restore . goes back to it (and throws away the changes).

See why QEMU crashed

qemu-system-i386 -kernel build/kernel.elf -no-reboot -d int,cpu_reset 2>&1 | tail -40

The last lines show the interrupts just before the reset. v=0d is a general protection fault, v=0e a page fault, v=08 a double fault. Paste them to your AI with the files you changed.

Find which line crashed

Take the eip from the panic screen and ask the toolchain which function it is in:

"$(brew --prefix llvm)/bin/llvm-addr2line" -f -e build/kernel.elf 0x00101234
addr2line -f -e build/kernel.elf 0x00101234     # if missing: sudo apt install binutils

Glossary

KernelThe core of an OS: the code that controls the hardware and runs everything else.
BootloaderThe small program that loads the kernel into memory and starts it. Ours is built into QEMU.
MultibootA standard way for a bootloader to find and start a kernel: a magic number and a few flags.
QEMUA program that pretends to be a whole PC, so your OS can run in a window.
FreestandingC code with no operating system and no C library under it.
Linker scriptTells the linker where each part of the program goes in memory.
StackMemory where C keeps local variables and return addresses. It grows downwards.
VGA text modeThe screen as 80 × 25 characters in memory at 0xB8000.
I/O portA number used to talk to a device with inb/outb, separate from memory addresses.
Serial portCOM1: sends text byte by byte. QEMU connects it to your terminal.
InterruptA signal that makes the CPU stop and run a handler, then continue.
ExceptionAn interrupt raised by the CPU because code did something wrong (0–31).
IRQAn interrupt request from a device: 0 is the timer, 1 the keyboard.
GDTGlobal Descriptor Table: memory segments. We set two that cover everything.
IDTInterrupt Descriptor Table: which handler runs for each interrupt.
PICThe chip that collects hardware IRQs and passes them to the CPU.
PITThe timer chip that ticks at a rate we choose.
ScancodeThe number a keyboard sends for a key's position.
PageA 4 KiB block of memory, the unit the OS hands out.
Bitmap allocatorKeeps one bit per page to know which ones are free.
Heap / kmallocWhere small pieces of memory come from when the kernel asks for them.
Triple faultA crash while handling a crash while handling a crash. The CPU resets.
