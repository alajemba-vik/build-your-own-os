A desktop with windows

The fun one. A desktop with a top bar, a clock and two windows you can move around, all drawn with text characters, like the first versions of many famous operating systems.

A shortened sketch of the real thing.

The idea

  • The VGA font (code page 437) has box-drawing characters: 0xC9 is ╔, 0xCD is ═, 0xB0 is ░… Enough to draw windows.
  • Double buffering: draw the whole picture in an array first, then copy it to 0xB8000 in one go. Drawing straight on the screen would flicker.
  • An event loop: check for a key without waiting (input_poll), update the state (which window is active, where it is), redraw, and sleep with hlt when there's nothing to do. Redraw a few times a second so the clock moves.
  • Draw the inactive window first and the active one last, so it's on top.

Do it

  1. The desktop

    Chapter 7. Add src/desktop.c with desktop_run(), started by a new shell command "desktop". Draw into a uint16_t buffer the size of the screen, then copy it to VGA memory in one go. Save the screen before and restore it when leaving.

    Draw: a textured background (character 0xB0), a top bar with the OS name on the left and the uptime on the right, a bottom bar with the keys, and two windows with a shadow. Use double box-drawing lines and a cyan title for the active window, single lines for the other. One window shows a welcome text, the other live system info: uptime, memory, free pages and the number of keys pressed. Add keyboard_presses() to keyboard.c for that.

    Keys: Tab switches the active window, arrow keys or WASD move it (keep it on the screen), Esc goes back to the shell. Use input_poll and redraw on every key and 4 times a second, sleep with hlt otherwise. Hide the blinking cursor while the desktop is open.

    make run

    Type desktop. Press Tab, move the windows with the arrow keys, Esc to go back.

  2. Make it yours

    Ask for one change at a time: your own colours, a third window (a clock, a notepad, a to-do list), a "start menu" on a key, or a tiny game inside a window. Snake fits nicely: it only needs the arrow keys, the timer and the screen.

Using make run-serial? The desktop is drawn on the screen, not sent to the serial port, so you won't see it there. Use make run or make run-text.

It works when

  • The clock in the top bar moves by itself.
  • Tab and the arrow keys work, and windows stay on the screen.
  • Esc brings back the shell exactly as it was.
